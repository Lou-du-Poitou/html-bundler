# HTML bundler
HTML bundler, generate optimized output of HTML, JS and CSS files 


## Usage

Install packages using the `package.json` file
```bash
npm install
```

## Config

Create a `gulpfile.config.json` file and define your configuration

```json
{
    "path_source": "src",
    "path_build": "dist",
    "dir_assets": "assets"
}
```

## Build

To build your application run the `gulp` command

```bash
gulp
```
